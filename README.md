# הולו (hulu)

אתר תדמית מקצועי להולו — עיצוב ובניית אתרים.
מינימליזם יוקרתי, RTL מלא, React + Vite + TypeScript + Tailwind CSS + shadcn/ui.

## הרצה

```bash
npm install
npm run dev
```

## סטאק

- React 19 + Vite + TypeScript
- Tailwind CSS v4
- shadcn-style UI (Button, Input, Label, Card)
- Framer Motion
- React Three Fiber (מודל מחשב אינטראקטיבי ב-Hero)

## הערות

- מספר הוואטסאפ והמייל הם placeholders — עדכנו ב־`Hero.tsx` ו־`Contact.tsx`
- ניתן להחליף את מודל ה־3D הפרוצדורלי בקובץ GLB תחת `public/models/`
